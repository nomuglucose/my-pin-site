MySugar

Health-data archiving application for blood glucose trend reporting.

MySugar allows users to save blood glucose trend reports as Pins on Pinterest boards they own. The application retrieves CGM (Continuous Glucose Monitoring) trend charts, generates daily and weekly report images, and publishes them using the Pinterest API. Users authenticate through Pinterest OAuth 2.0 and only authorized accounts can create Pins.
